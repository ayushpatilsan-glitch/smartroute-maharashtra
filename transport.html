Transportation Modes

SmartRoute models each mode as a type of weighted edge in the graph. Fares and times shown are estimated demo values.

🚌

Bus (PMPML / City)

Primary public transport across Pune & PCMC. Edges store route number, stops, distance, time and fare.

Example: Katraj → Swargate → Pune Station · Route PMT-12

🚇

Metro

Purple & Aqua lines (sample). Fast, fixed stops. Ideal for mid-city corridors with low transfer cost.

Vanaz → Anand Nagar → Ideal Colony → Deccan → Civil Court

🛺

Auto Rickshaw

Door-to-door flexibility. Higher fare, often faster for short/medium trips. All values labelled estimated.

Katraj → Swargate · ~6.2 km · ~20 min · estimated fare

🚆

Local / Regional Train

Pune–Lonavala corridor and suburban stops (Pimpri, Chinchwad, Akurdi, Nigdi). Low fare, fixed schedule style.

🚕

Taxi / Cab

Direct point-to-point. Highest fare, lowest transfer count. Useful baseline for comparison.

🚶

Walking

Short last-mile or station-to-station links. Zero fare, higher time. Often used between metro and bus stops.

Data Model per Connection

{
  source: "Pune Railway Station",
  destination: "Shivajinagar",
  mode: "Bus",
  distance: 3.5,      // km
  time: 15,           // minutes
  fare: 15,           // ₹ estimated
  routeNumber: "PMT-101",
  stops: ["Pune Railway Station", "Bund Garden", "Shivajinagar"]
}

Stored as directed edges in an adjacency list. Easy to swap static JSON for a live transportService / fareService later.
